# Data for You Can Just Do Things

Reader companion to the second edition of *You Can Just Do Things: A Data Portrait of
John D. Cook's Blog*.

These files let you inspect selected archive measurements and repeat the book's accompanying
calculations. Start with [the reader guide](reader-files/README.md), find a question in
[the section map](reader-files/unit-to-file.md), or look up a field in
[the data dictionary](reader-files/data-dictionary.md).

The edition download contains the complete set of tables, guides and a Python checker.
Use the release identified in the book to reproduce that edition's results. The checker
uses Python's standard library and needs no account or network connection.

The archive measurements cover public posts published before November 1, 2026, using the
captured versions described in the guide. They support selected counts and examples; they
do not recreate the full historical website. The guide distinguishes recorded observations,
supplied classifications and calculations that the checker repeats.

John D. Cook's writings and code excerpts retain their attribution. The companion's selection,
analysis and explanatory material were developed under Owen D. Goode's direction for the book.
Source links and version details accompany the data. This companion does not apply a blanket
reuse license to the cited source material.
